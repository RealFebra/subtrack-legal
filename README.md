# subtrack-legal

Public legal documents for the SubTrack mobile app.

- `privacy.md` — Privacy Policy
- `terms.md` — Terms of Service
- `index.md` — Landing page

Hosted via GitHub Pages from the root of the `main` branch.

URLs (after enabling Pages):

- https://realfebra.github.io/subtrack-legal/privacy
- https://realfebra.github.io/subtrack-legal/terms

## Updating

Edit the markdown files directly on GitHub or locally, commit, push. GitHub Pages rebuilds within ~1 minute.
